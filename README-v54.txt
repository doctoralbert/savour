SAVOUR v54

Based on savour-v53.

Changes:
- Approved SAVOUR gold logo integrated into landing, app/sidebar and mobile header.
- Transparent SAVOUR favicon using the approved S emblem.
- Mobile search icon moved farther right before favorite/logout controls.
- Shared-map view constrained to mobile width with no horizontal overflow; mobile cards/folders remain inside viewport.
- Landing hero decorative card removed. Platform/device section moved directly after hero for stronger first impression.
- Centralized language hardening: URL language is authoritative on public pages, translation overlay expanded, dynamic DOM MutationObserver re-translates newly rendered UI, and user content remains protected.

No Supabase schema changes are required for these UI-only changes.
