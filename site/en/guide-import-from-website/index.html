Import a recipe from a website

Paste the link of a recipe page and Savour pulls out the recipe, without ads and life stories.

On this pageHow it worksWhat Savour readsNo recipe foundPages behind a loginCredit the source

How it works

Choose “Add recipe” → “Import recipe” → “Web page (link)”. Paste the link of the recipe page and choose “Process”. You need to be logged in.

What Savour reads

Most recipe sites publish their recipes in a standard format (schema.org) inside the page. Savour reads it directly: title, ingredients, method and yield. If the recipe is not in that format, the Savour reader reads the page text, and with Pro the AI where needed.

No recipe found

If Savour finds no recipe on the page, it tells you and nothing is made up. In that case copy the recipe text and use Enter text.

Pages behind a login

Savour cannot open pages that need a login or payment. Copy the text, or save the page as .html and import it under Other files.

Credit the source

Using someone else’s recipe? Put the source in a note on the recipe.
