Import recipes from notes apps

Recipes scattered across notes on your phone? This is how you get them into Savour.

On this pageThe quick wayApple NotesGoogle DocsMicrosoft OneNoteNotionObsidian, Bear, Joplin and SimplenoteEvernote and Google Keep

The quick way

For one or a few recipes: open the note, copy the text and paste it under Enter text. You can paste several recipes at once.

Apple Notes

On a Mac select a note and choose File → Export as PDF, then import that PDF. On an iPhone, copy the text and paste it under Enter text.

Google Docs

Choose File → Download → Microsoft Word (.docx) and import the Word file. One document with all your recipes is fine.

Microsoft OneNote

Export a page or section as Word or PDF (File → Export) and import that file. You can also copy and paste a single page.

Notion

On the page with your recipes choose ⋯ → Export → Markdown & CSV. You get a zip with .md files; pick that zip under “All files mixed”. See A whole folder or zip.

Obsidian, Bear, Joplin and Simplenote

These apps store notes as Markdown or text, or can export them that way. Pick the folder of .md or .txt files with “Choose a whole folder”, or put them in a zip. Each file is then a recipe, with the # heading as the recipe name.

Evernote and Google Keep

Savour has its own import for these: see Evernote and Google Keep.
