JSON, schema.org and Savour files

Recipes that are already neatly in fields: from another program, a website or your own backup.

On this pageschema.org RecipeJSON filesRestoring your Savour backupSavour import file

schema.org Recipe

Many programs and websites store recipes in the schema.org Recipe format, as JSON-LD or inside HTML. Savour reads the name, ingredients, method (including steps and sections), yield, category and notes.

JSON files

Pick a .json file under “Other files” or “From another recipe app”. Savour finds the recipes in the file itself, also in a list or in a Mealie or Tandoor export. Savour cannot read an arbitrary JSON file without recipes in a recognisable form.

Restoring your Savour backup

A backup you download from Savour (.json) can be imported again under “Other files”. The recipes appear in the review screen; recipes already in your library exactly like this are not saved twice.

Savour import file

With the import service you sometimes receive a Savour import file (.json) with recipes that have already been read and checked. Pick it under “Other files” too; nothing is saved until you click Save.
