Imprimir recetas

Imprime una receta para la pared o una carpeta de recetas completa para el archivador. Rápido, limpio y siempre la versión correcta.

Imprimir una receta suelta

Abre una receta y elige Imprimir. Obtienes una página tranquila con título, rendimiento, ingredientes y elaboración. ¿Has escalado la receta, por ejemplo a 40 cubiertos? Entonces imprimes justo esas cantidades.

Imprimir una carpeta de recetas completa

¿Todas las recetas de helado tienen que ir a la carpeta de pastelería? Abre la carpeta e imprímela de una vez: cada receta en su propia página, en el orden de tu carpeta. Se acabó imprimir cincuenta archivos uno a uno.

Diseño tranquilo

Grande y claro. Legible a un metro, incluso con una mancha encima.

Siempre la última versión

Como imprimes desde Savour, en la pared siempre está la versión correcta. Abajo aparece la fecha de impresión, para que veas si una carpeta sigue al día.

Con el logo de tu restaurante

Con Savour Pro, cada página lleva arriba el logo y el nombre de tu restaurante. En una brigada, el logo vale para todos. Elige A4 para la carpeta o A5 para una carpeta pequeña en el pase.
