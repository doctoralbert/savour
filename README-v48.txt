Savour v48

Basis: v47.

v48 mobile-only refinements:
- Mobile bottom navigation simplified to Recepten / Recept mappen / Gedeelde mappen / Account.
- Mobile search button remains available in the top bar and opens the same Alle recepten page/search.
- Mobile recipe category chips are hidden; desktop categories remain unchanged.
- Mobile recipe cards no longer show ingredient/method-step counts.
- Mobile recipe actions are compact icon buttons placed below the recipe content.
- Mobile shared-map recipe actions use the same compact treatment.
- Mobile logo is clickable and returns to Alle recepten.
- Mobile input font sizing prevents iOS automatic zoom on focus.
- Mobile Account page includes an Uitloggen button.
- Mobile navigation labels updated to Recept mappen and Gedeelde mappen.
- Recipe detail back navigation now remembers whether the recipe was opened from personal recipes, a personal folder, a shared map, or a shared folder, for both desktop and mobile.
- Existing desktop functionality, Supabase logic, AdSense code, language system, import flow, and data rules are preserved.
