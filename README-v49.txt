Savour v49

Basis: v48

Focus of this release:
- Mobile logged-out landing keeps both Inloggen and Account aanmaken visible.
- Login can remember the login email and optionally store credentials through the browser Credential Management API; passwords are not stored in localStorage.
- Logged-in mobile opens directly on Alle recepten.
- Mobile topbar: clickable SAVOUR logo, search, favorites and logout; no redundant hamburger menu.
- Mobile bottom navigation: Recepten, Recept mappen, Gedeelde mappen, Account.
- Mobile footer restored with public pages and language selector.
- Shared map chooser lets users select which shared map to open when multiple exist.
- Shared map actions are compact and photo is smaller.
- Mobile recipe cards are significantly more compact.
- A t/m Z personal and shared folders now use persistent A-Z controls with filtering instead of scroll-to-letter behavior.
- Mobile A-Z folders render the actual recipe list from the library/shared map.
- Recipe detail and shared-folder navigation keep their originating context.
- Existing desktop functionality, Supabase integration, AdSense and v48 behavior are preserved unless explicitly noted above.
